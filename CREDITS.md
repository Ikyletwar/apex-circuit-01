## Aset visual

Semua tekstur, decal, papan iklan, banner start/finish, sprite matahari, dan geometry dibangkitkan saat runtime memakai Canvas 2D dan Three.js di `app.js`. Tidak ada berkas gambar/model pihak ketiga yang disertakan.

## Audio

Seluruh suara disintesiskan dengan Web Audio API di `app.js`: oscillator sawtooth untuk mesin, oscillator square untuk beep, dan noise buffer untuk impact. Tidak ada berkas audio yang disertakan.
